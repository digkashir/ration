# Рацион — планировщик еды

Личный планировщик питания: рецепты, КБЖУ, порции для каждого и список покупок. Работает в браузере и на Android (можно установить на главный экран). Данные хранятся на Google Диске пользователя.

Сайт: https://digkashir.github.io/ration/

Код пишет Claude. Требования и история решений ведутся в project state проекта «Планировщик еды».

## Версии

- **v0.2 «Рецепты»** — база рецептов с фильтрами по тэгам и поиском по названию и ингредиентам; карточка рецепта в боковой панели (КБЖУ на порцию или на весь рецепт, сворачиваемые ингредиенты, все шаги); правка на месте (ингредиенты в граммах или штуках, шаги с перетаскиванием, тэги и автотэги); группы рецептов-вариантов.
- **v0.1 «Каркас»** — вход через Google, база на Google Диске, офлайн-режим, синхронизация, база ингредиентов.

## Устройство кода

Сборки нет: обычные ES-модули, GitHub Pages отдаёт файлы как есть.

| Файл | Что внутри |
|---|---|
| `js/app.js` | каркас: вход, разделы, слои поверх страницы, обработка событий |
| `js/store.js`, `js/sync.js`, `js/drive.js`, `js/db.js` | данные: локальная копия (IndexedDB), слияние, Google Диск |
| `js/migrate.js` | приведение старых данных к текущей схеме (выполняется при каждом чтении) |
| `js/ui.js`, `js/util.js` | общее состояние интерфейса, действия, мелкие функции |
| `js/nutrition.js` | КБЖУ и правила автотэгов |
| `js/ingredients.js` | раздел «Ингредиенты» |
| `js/recipes.js`, `js/recipe.js`, `js/groups.js` | раздел «Рецепты»: список, карточка и правка, группы |
| `sw.js` | офлайн-кэш интерфейса (версия меняется с каждым выпуском) |
