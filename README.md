# Рацион — планировщик еды

Личный планировщик питания: рецепты, КБЖУ, порции для каждого и список покупок. Работает в браузере и на Android (можно установить на главный экран). Данные хранятся на Google Диске пользователя.

Сайт: https://digkashir.github.io/ration/

Код пишет Claude. Требования и история решений ведутся в project state проекта «Планировщик еды».

## Версии

- **v0.3.2** — интерфейс на всю ширину экрана, шире список рецептов в плане и подсказка с полным названием, перетаскивание в списке рецептов плана (новая группа, добавить в группу, порядок), переключатель периода всегда справа.
- **v0.3.3 «Готовка»** — режим плана «по дням приготовления»: перенос блюд по дням готовки (не позже приёма и не раньше чем за 5 дней), похожие блюда в одном дне — одна готовка, фильтр по «*»; список рецептов плана больше не прыгает наверх и показывает все рецепты.
- **v0.3.4** — в окне блюда плана виден рецепт (ингредиенты на порции приёма или на 1 порцию, шаги; для нескольких вариантов — переключатель), рецепт в окне добавления и в окне персоны; вся ячейка приёма (день × персона) открывает окно персоны.
- **v0.4 «Экспорт»** — страница «Покупки и гид»: список покупок по отделам с флажками «куплено» и ручной правкой количества, готовки по дням приготовления с рецептом на нужные порции, флажок «не покупать» у ингредиента (по умолчанию вода и соль); выгрузка в Google Таблицу «Рацион — покупки и гид» (листы «Список покупок» и «Гид»). Нужно включить Google Sheets API (setup-guide, шаг 2.6).
- **v0.3 «План»** — персоны с целями по КБЖУ; план по дням приёма (сегодня + 6 дней, день, месяц, свой период); блюда и ингредиенты без рецепта по приёмам, порции и варианты группы для каждой персоны, свой вариант блюда (экземпляр) и сохранение его как рецепта; «*» — похожие блюда в ±5 днях; перетаскивание из базы рецептов; итоги дня с подсветкой перебора; экран тэгов.
- **v0.2.1** — перетаскивание рецептов в группы и внутри групп.
- **v0.2 «Рецепты»** — база рецептов с фильтрами по тэгам и поиском по названию и ингредиентам; карточка рецепта в боковой панели (КБЖУ на порцию или на весь рецепт, сворачиваемые ингредиенты, все шаги); правка на месте (ингредиенты в граммах или штуках, шаги с перетаскиванием, тэги и автотэги); группы рецептов-вариантов.
- **v0.1 «Каркас»** — вход через Google, база на Google Диске, офлайн-режим, синхронизация, база ингредиентов.

## Устройство кода

Сборки нет: обычные ES-модули, GitHub Pages отдаёт файлы как есть.

| Файл | Что внутри |
|---|---|
| `js/app.js` | каркас: вход, разделы, слои поверх страницы, обработка событий |
| `js/store.js`, `js/sync.js`, `js/drive.js`, `js/db.js` | данные: локальная копия (IndexedDB), слияние, Google Диск |
| `js/migrate.js` | приведение старых данных к текущей схеме (выполняется при каждом чтении) |
| `js/ui.js`, `js/util.js` | общее состояние интерфейса, действия, мелкие функции |
| `js/nutrition.js` | КБЖУ и правила автотэгов |
| `js/ingredients.js` | раздел «Ингредиенты» |
| `js/recipes.js`, `js/recipe.js`, `js/groups.js`, `js/recipe-dnd.js` | раздел «Рецепты»: список, карточка и правка, группы, перетаскивание |
| `js/plan-model.js`, `js/plan.js`, `js/plan-dnd.js` | план: даты, записи и снимки рецептов, экран плана, перетаскивание |
| `js/persons.js`, `js/tags.js` | персоны и экран тэгов |
| `sw.js` | офлайн-кэш интерфейса (версия меняется с каждым выпуском) |
